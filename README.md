# Minimal UI for KOReader

轻量的 KOReader Home 与 Library 界面，适用于键盘、少键和触屏电子阅读器。

**v0.6.6** 提供继续阅读、最近阅读、Favorites独立入口、统一书籍列表／网格、六插槽底栏与硬件键盘列表快捷键，并修复Reader返回Home时重复提取封面的开销。阅读器、设置、文件操作与元数据仍复用KOReader原生能力。

使用 `minimalui-v0.6.6.zip` 安装，旧 `minimalui-v0.6.5.zip` 保留回退。打包及Git推送不等于创建GitHub Release；桌面验证不能代替Kindle实机响应与电子墨水验收。

## 安装

1. 使用 `minimalui-v0.6.6.zip` 安装包时，解压后直接使用其中的 `minimalui.koplugin` 目录。也可下载仓库源码ZIP并将目录命名为 `minimalui.koplugin`，或使用Git（仓库版本以 `_meta.lua` 为准）：

   ```sh
   git clone https://github.com/W-874/minimalui.koplugin.git
   ```

2. 完全退出 KOReader，将 `minimalui.koplugin` 放入 KOReader 的 `plugins/` 目录。
3. 重新启动 KOReader。从原生工具菜单的 **Minimal UI** 中启用插件或选择 **Show home**。

安装后的目录应为：

```text
koreader/plugins/minimalui.koplugin/
├── main.lua
├── _meta.lua
├── minimalui/
├── README.md
└── LICENSE
```

`main.lua` 必须直接位于插件目录下，不要再套一层同名目录。

### 升级与卸载

升级前完全退出 KOReader，备份并替换原插件目录。从旧 `minimalhome.koplugin` 升级时，请先移走旧插件，避免两个版本同时加载。已有书籍、阅读进度和排版设置无需重置。

暂时停用可使用 **Minimal UI → Enable Minimal UI**。卸载时完全退出 KOReader，移除插件目录即可。

## 功能

### Home

- **继续阅读**：打开上次阅读的书籍，显示封面、书名、阅读进度，以及已有的作者和章节信息。
- **最近阅读**：显示最多三本其他最近阅读的书籍，方便快速切换。
- **阅读统计**：启用 KOReader 原生阅读统计插件后，显示已有的今日及本周阅读时长。
- **快捷入口**：Library、History、Favorites、File Browser。
- **状态顶栏**：时间、电量与原生设置菜单入口。

章节、剩余时间等信息依赖已保存的阅读数据；没有对应数据时不显示。Minimal UI 不会改动正文渲染、字体、排版或翻页方式。

### Favorites 与书单

主页的 **Favorites** 直接打开原生收藏内容，Back／返回箭头关闭收藏页并回到主页，保留主页选择。收藏仍使用原生内置 `favorites` 书单，不迁移数据、不新建收藏数据库，书籍操作、列表／网格与封面提取仍复用原生功能。

普通书单浏览页不再显示内置收藏，只列用户自建书单；“加入书单”的归类选择器仍保留收藏，可正常加入／移出。仅有收藏而无自建书单时，书单浏览页为空。保存过“默认打开收藏”时，插件启用期间不让该设置绕过书单浏览；保存值不变，其他默认书单保持原生行为。

插件启用期间，文件管理器与阅读器的原生 Menu 不再重复提供 History／Favorites 入口；书单管理、跨书书签和历史显示设置仍保留。停用插件后，原生菜单、书单中的收藏行与收藏返回路径均恢复；已有收藏数据不变。不依赖 CoverBrowser 是否启用。

### Library

Library 用于浏览 Kindle `documents` 目录当前层的书籍，不混排子目录。进入 Library 时更新书籍列表，按文件名排序。

启用 KOReader 的 CoverBrowser 插件后，Library、History、单个收藏内容和搜索结果共用原生 **History display mode** 设置，提供书名详细列表或封面网格；已保存的 Classic／文件名列表映射为书名列表，不覆盖原设置。未启用 CoverBrowser 时回退为简单列表，不代为加载封面模块。

**Files** 保留独立显示模式与文件名、目录和文件属性。插件启用时隐藏统一显示模式、收藏独立显示模式及简介提示菜单，不改写其保存值；停用插件后恢复原生。目录浏览、文件移动等操作仍使用独立的 **File Browser** 入口。

已适配分页页使用六插槽底栏：返回上级、Home／Close、上一页、页码、下一页、页面操作。600px 宽基准每个热区为 72×50px，按实际宽度等比缩放；上一页／下一页在边界置灰，页码点按／长按复用原生跳页或搜索。一页仍可跳页，空页保留原生“无项目”。OPDS 根不显示返回上级，子目录显示；OPDS 和阅读中书签使用 Close 返回调用者，其余页面使用 Home。

顶栏只保留下拉箭头、标题与状态；箭头点击、顶栏空白或下滑仍打开原生设置。按键焦点不再进入顶栏，直接使用硬件Menu键；Files添加／选择、History／书单／Search管理操作在底栏右侧。Home自身无底栏。

书单管理、归类选择器、OPDS目录／下载、跨书书签及阅读中书签统一使用新Classic行，列表与Classic恢复灰色行间细分割线（末行不额外画线）。普通书单标题为KO/<原小标题>；Favorites固定为KO/FAVORITES，不显示重复副标题。原生数据与回调保留。

在 Home 或 Library 中长按书籍，可使用原生阅读状态、收藏、删除、打开方式、书籍信息、封面和简介等操作。键盘设备也可使用原生上下文菜单组合键，如 Shift + Press。

## 操作

| 设备 | 操作 |
| --- | --- |
| 键盘／方向键 | 方向键移动选中项；Press／Enter 打开选中项；Menu 打开原生设置。 |
| 少键设备 | 上下移动选中项，确认键打开；Home 的 Left 返回，Right 打开设置。 |
| 触屏 | 点击卡片或入口打开；长按书籍显示操作菜单；点击顶栏空白处或从顶栏下滑打开设置。 |

键盘设备的 Home 快捷键：

| 按键 | 功能 |
| --- | --- |
| Q / W / E | 从左至右打开三本最近阅读的书籍 |
| L | Library |
| H | History |
| C | Favorites（收藏） |
| F | File Browser |

Press／Enter 始终打开当前选中项，不固定指向继续阅读卡片。

详细列表及Classic仅硬件键盘显示Q/W/E/R…角标并打开当前页条目，支持翻页／热插拔；非键盘触屏／少键无字母角标及绑定，网格无角标。方向键只在正文与底栏间移动，底栏左右循环；顶栏不占焦点行，Menu键直接打开设置。

### 页面返回

- Library、File Browser 和从主页打开的 Favorites 的 Back／Home 返回 Home；Favorites 的返回箭头也直接回主页。
- Home 的 Back 打开退出确认；取消后留在 Home。
- 原生设置菜单直接覆盖当前页，返回时先关闭菜单。
- 未修改显示设置时，关闭菜单保留已有行、文字／图片控件及页面表面；设置确实变化时只更新受影响页面，隐藏的 Files 也会在需要时更新。行数／网格对话框保存后再应用到书籍页，避免关闭菜单时过早或重复重建。
- 阅读器中的 File browser 菜单入口返回 Library；实体 Home 键返回 Home。

## Home 显示设置

打开 **Minimal UI → Home appearance**，可分别开关：

- **Recent books**：最近阅读卡片。
- **Book covers**：书籍封面。
- **Book information**：作者、章节等附加信息。
- **Reading statistics**：阅读时长。
- **Navigation details**：Library与Favorites显示数量，空／来源不可用显示0；History显示有效历史数量，File Browser显示当前路径。Library使用与书库相同的当前层／格式／符号链接规则计数，不排序或加载元数据。

开关只影响 Home 显示，不删除书籍或阅读数据。原生阅读器与 CoverBrowser 的设置仍在各自菜单中调整。

## v0.6.5 底栏、列表与性能更新

- 六固定插槽底栏复用原生分页、返回与输入按钮；动态 Home／Close、管理／添加／选择，停用恢复原生组件与方法。
- Collection、OPDS 和书签等原生列表采用新 Classic 行；书单标题内联为 `KO/<小标题>`；保留 Favorites 数据、归类选择器与独立返回主页路径。
- 列表／Classic 恢复硬件键盘 QWERTY 快捷入口，非键盘设备不显示；热插拔、分页和可变行高页均按原生数据映射。
- 阅读中书签的底栏 Close 返回 Reader，顶栏 Menu 仍打开 Reader 设置；OPDS 弹窗锚点使用实际底栏图标。
- 底栏控件、可见性和焦点成员均未变化时不再重复移除／插回焦点行或扫描正文；变更图标、翻页、重建和焦点移除仍按原生状态同步。
- 快捷键采用弱所有权记录被替换的按键表，避免持续热插拔累积旧表；被第三方保留的旧包装在停用后只转发原生回调，不重新挂接功能。
- Library 在原生首次尺寸计算前准备底栏，首次进入／重建只构造一遍条目，不再由底栏初装递归触发第二遍构造；正文、50px基准底栏与分页均正常布局。

## v0.6.1 更新

- 原生页面与 Library 共用按实际消费者比较的显示设置状态，未变更菜单不再重建当前页和隐藏 Files；保留原生日期、字体、进度、Series、提示、行数和网格设置的即时更新。

- 保持文字／图像原生合成；圆角、透明或自定义背景走原路径。停用、页面关闭和原生重建时恢复实例方法。
- 修复同一有效书籍模式下刷新 Library 时，纯触屏被错误要求显示焦点的边界；页位置与键盘选择仍保留。

## v0.6.0 更新

- Library、History、Collections、Search 和 Files 使用统一黑白列表／网格；单行书名省略、阅读进度、收藏状态与已读标记沿用原生数据。网格不添加底部详情行。
- 列表用左侧黑条、网格用方框表示焦点；纯触屏不强制显示选中框。页面表面缓存按缓冲格式、inverse 和旋转失效，菜单关闭后恢复完整页面。
- 三区页脚复用原生按钮与输入对话框；书籍信息页在初始化、翻页和旋转后保留页脚，禁用时恢复原字体和控件。
- 封面后台提取按页面实例管理，翻页、模式切换及关闭取消过期任务；关闭停放的旧页面不会终止新页面的提取。
- 不改变 Home 布局、书库范围、排序或阅读排版；不按 Kindle 型号设置性能分支。

本版本使用官方 KOReader v2026.07.1 Linux SDL 验证。桌面绘制／像素检查不能证明 Kindle 实机响应、电子墨水残影或长期稳定性；安装前保留旧版插件以便回退。
